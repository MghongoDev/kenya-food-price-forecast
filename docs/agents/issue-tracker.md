# Issue tracker: GitHub Issues

Issues for this repo live in GitHub Issues and are managed with the `gh` CLI.

## Rules for agents

- Create issues with `gh issue create --title "..." --body "..."` (add `--label` when relevant).
- List and read issues with `gh issue list` / `gh issue view <n>`.
- Never create issues as markdown files or on another tracker; this file is the source of truth for where issues live.
- Cross-reference issues in commits and PRs with `#<n>`.
